================================================================================
                    3RD PARTY PACKAGES DOCUMENTATION
                    NutriConnect WBD (Web-Based Diet) Project

This document lists all external/third-party packages installed via npm that are
used in the NutriConnect project, organized by category and purpose.

================================================================================
BACKEND DEPENDENCIES (Node.js)
================================================================================

1. EXPRESS (^5.1.0)
   - Purpose: Web application framework for Node.js
   - Used for: Building REST API endpoints, routing, middleware
   - Key Features: Lightweight, flexible, widely adopted

2. MONGOOSE (^8.18.1)
   - Purpose: MongoDB object modeling (ODM)
   - Used for: Database schema definition, queries, validation
   - Key Features: Schema validation, middleware hooks, query building

3. JSONWEBTOKEN (^9.0.2)
   - Purpose: JWT creation and verification
   - Used for: User authentication, token generation, authorization
   - Key Features: Sign tokens, verify tokens, extract claims

4. BCRYPTJS (^3.0.2)
   - Purpose: Password hashing and encryption
   - Used for: Secure password storage, password verification
   - Key Features: Salt-based hashing, async operations

5. DOTENV (^17.2.2)
   - Purpose: Environment variable management
   - Used for: Load .env files, manage sensitive configuration
   - Key Features: Secure API keys, database credentials storage

6. CORS (^2.8.5)
   - Purpose: Enable Cross-Origin Resource Sharing
   - Used for: Allow frontend to communicate with backend API
   - Key Features: Origin control, method control, credential handling

7. HELMET (^8.1.0)
   - Purpose: HTTP security middleware
   - Used for: Set security headers, protect against vulnerabilities
   - Key Features: HSTS, CSP, XSS protection

8. EXPRESS-RATE-LIMIT (^8.2.1)
   - Purpose: Rate limiting middleware
   - Used for: Prevent API abuse, DoS attack prevention
   - Key Features: Request limiting, configurable windows

9. MORGAN (^1.10.0)
   - Purpose: HTTP request logger middleware
   - Used for: Log API requests, monitor traffic
   - Key Features: Format logging, stream to files/database

10. MULTER (^2.0.2)
    - Purpose: File upload handling middleware
    - Used for: Handle multipart/form-data, process file uploads
    - Key Features: Multiple file support, field validation

11. CLOUDINARY (^2.8.0)
    - Purpose: Cloud storage and CDN service
    - Used for: Store images, videos, files in cloud
    - Key Features: Image transformation, CDN delivery, optimization

12. NODEMAILER (^7.0.10)
    - Purpose: Email sending library
    - Used for: Send OTP emails, notifications, confirmations
    - Key Features: SMTP support, HTML emails, attachments

13. AXIOS (^1.12.2)
    - Purpose: HTTP client for API requests
    - Used for: External API calls, data fetching
    - Key Features: Promise-based, interceptors, timeout handling

14. @GOOGLE/GENERATIVE-AI (^0.24.1)
    - Purpose: Google's Generative AI API integration
    - Used for: AI chatbot, natural language processing
    - Key Features: LLM access, streaming responses

15. ROTATING-FILE-STREAM (^3.2.8)
    - Purpose: Log file rotation utility
    - Used for: Manage application logs, prevent disk overflow
    - Key Features: Size-based rotation, date-based archiving

16. NODEMON (^3.1.10)
    - Purpose: Development utility for auto-restart
    - Used for: Auto-restart server on file changes
    - Key Features: File watching, configurable delay, script debugging
